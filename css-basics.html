CSS Basics

CSS is what makes a website look the way it does. It controls things like colors, fonts, spacing, and layouts.

What Is CSS?

CSS stands for Cascading Style Sheets. It works with HTML to change how a webpage looks.

CSS uses selectors to choose which HTML elements to style. Then, properties and values tell the browser what to change. 

h1 {
  color: blue;
  font-size: 2rem;
}

Common CSS Properties

Colors

CSS lets you change the color of text and other elements.

p {
  color: blue;
}

Fonts

You can change the font and size of your text.

body {
  font-family: Arial;
}

Spacing

Margin and padding help create space between elements.

.card {
  padding: 1rem;
}

Backgrounds

Background colors can help separate different sections.

.card {
  background: lightgray;
}

Flexbox and Grid

Flexbox and CSS Grid are two ways to organize content on a webpage. Flexbox is useful for arranging items in a row or column. Grid is helpful when you want to create layouts with rows and columns.

How I'm Using CSS

For this website, I'm using shared CSS classes and variables so I don't have to repeat the same styles on every page. 

.cards {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 1rem;
}
