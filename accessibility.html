Accessibility

Web accessibility is about making websites easier for everyone to use. This includes people who use keyboards, screen readers, or other tools to browse the internet.

Accessibility Basics

Headings

Headings help organize a webpage. Use them in the right order so people can understand how the content is arranged. 

<h2>About This Page</h2>

Alt Text

Alt text describes an image for people who cannot see it. Images that are only for decoration can have empty alt text. 

<img src="dog.jpg" alt="A dog sitting on grass">

Keyboard Navigation

People should be able to move through links using a keyboard. A visible outline helps show which link is selected. 

a:focus-visible {
  outline: 3px solid orange;
}

Color Contrast

Text should be easy to read against its background. Dark text on a light background is one common example. 

body {
  color: #24313a;
  background-color: white;
}

Try Using Your Keyboard

Press the Tab key to move between links on this page. You should see an outline around the link you're currently on.

You can also press Shift + Tab to move backward.

Why Accessibility Matters

Small changes like using proper headings, readable colors, and keyboard-friendly navigation can make a website easier for more people to use.
