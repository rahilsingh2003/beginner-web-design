Responsive Design

Responsive design helps websites work on different screen sizes. By using flexible layouts, images, and CSS, a website can adjust to phones, tablets, and desktop computers.

Why Responsive Design Matters

People use all kinds of devices to browse websites. A website that looks good on a computer might be difficult to use on a smaller phone screen.

Responsive design helps fix this by adjusting the layout so the content stays readable and easy to navigate.

Basic CSS Media Queries

Media queries let us change CSS styles depending on the screen size.

In this example, the cards start in one column. At 768px they change to two columns, and at 1200px they change to three. 

.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

@media (min-width: 768px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1200px) {
  .cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

Flexible Images

Images should also adjust to different screen sizes. Using max-width: 100% helps prevent an image from stretching outside its container. 

img {
  max-width: 100%;
  height: auto;
}
