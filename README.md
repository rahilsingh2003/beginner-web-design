
# GIT 414 - Module 2 CSS Architecture Package

## Project Overview

For my capstone project, I'm creating a website called Beginner's Guide to Web Design. It's a five-page website that introduces beginners to HTML, CSS, responsive design, and accessibility.

For Module 2, I focused on organizing the CSS so I can reuse the same styles throughout the website. This is still an early version, so the design isn't completely finished yet.

## Project Files

- `index.html` - Homepage with an introduction and topic cards.
- `html-basics.html` - Basic HTML explanations and examples.
- `css-basics.html` - Basic CSS explanations and examples.
- `responsive-design.html` - Examples of responsive layouts.
- `accessibility.html` - Introduction to web accessibility.
- `css/styles.css` - Main stylesheet with layers, variables, components, and print styles.
- `docs/ARCHITECTURE_NOTES.md` - Explains how I organized my CSS and what I changed.
- `docs/TEST_CHECKLIST.md` - Checklist for testing the website.

## How to Open the Website

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and select "Open with Live Server."
4. Use the navigation links to explore the five pages.

The website uses HTML and CSS, so no JavaScript or additional setup is needed.

## Testing

I tested the website locally using VS Code's Live Server and Chrome DevTools.

I checked the homepage at 375px and 1280px to make sure the responsive layouts worked correctly. I also tested the navigation links, visible keyboard focus indicators, and the homepage's print preview.

The tests I completed did not reveal any major issues. I recorded the results in docs/TEST_CHECKLIST.md, including which additional checks have not been completed yet.
