HTML Basics

HTML is what gives a webpage its structure. Let's go over some common HTML elements and see how they work.

What Is HTML?

HTML stands for HyperText Markup Language. It tells the browser what different parts of a webpage are, like headings, paragraphs, links, and images.

HTML uses tags to organize content. Most elements have an opening tag and a closing tag. CSS is then used to change how those elements look.

HTML Page Structure

Heading: <h1>
Paragraph: <p>
Link: <a>

Common HTML Elements

Headings

Headings help organize a webpage into different sections. HTML has six heading levels, from h1 to h6. 

<h1>My First Page</h1>
<h2>About Me</h2>

Paragraphs

Paragraphs are used for regular text on a webpage. 

<p>Hello, world!</p>

Links

Links let people move between pages or visit other websites. 

<a href="css-basics.html">Learn CSS</a>

Images

Images use the img tag. The alt attribute provides a text description when the image needs one. 

<img src="cat.jpg" alt="A sleeping cat">

Basic HTML Document

Here's an example of a simple HTML page. The head section contains information about the page, while the body contains the content people actually see.

Try It Yourself

Copy this example into a new HTML file and open it in your browser to see what happens. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is my first webpage.</p>
</body>
</html>
